# 光谷购房决策库 🏠

武汉东湖高新区（光谷）购房决策持续跟进仓库。目标：2027 年（最晚 2028 年）在光谷买房。

## 文件结构

| 文件 | 内容 |
|------|------|
| `00-光谷购房分析总报告.md` | 板块框架、价格趋势、2027 预测、时点判断 |
| `01-二手房小区成交明细.md` | 各板块小区真实成交价（贝壳成交记录/购房荟月报口径） |
| `02-新房楼盘网签明细.md` | 在售楼盘网签实价（克而瑞/普睿数智监测口径） |
| `03-跟进计划与看房清单.md` | 看房优先级清单、每月数据源、风险监控触发器 |
| `04-重点户型对比分析.md` | 万家九城 106 / 宜居友家 113/90 户型横向对比（基于逯薇《小家》系列方法论） |
| `05-市场动态与数据更新.md` | 2026-08-28 增补：官方月度成交（5-7月）、8·21 土拍、70 城 7 月数据、政策核校、挂牌量口径更正 |

## 数据口径原则

- 二手房只用**成交价**（贝壳已成交记录、购房荟月报明细），挂牌价仅用于计算议价空间
- 新房只用**网签价**（克而瑞/普睿数智监测），不信售楼处报价

## 更新约定

每月月底更新成交数据；出现重大事件（土拍、政策、风险触发器）随时更新。每次更新后同步推送本仓库。

自 2026-08-28 起，月度数值优先与「武汉市住房和城市更新局」官网月度简报核对（见 `05` 文件第五节），挂牌量为市场口径时单独标注。

*仅供个人购房决策参考，不构成投资建议。*
